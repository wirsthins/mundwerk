So klingt Tirolerisch: die wichtigsten Lautregeln

RegelErklärungBeispiele
ei → oaDas alte ei wird zu oa. Gilt nicht für jedes ei: Eis und Wein bleiben gleich.heiß → hoaß, zwei → zwoa, klein → kloan, Stein → Stoan
ü ö → i eGerundete Vokale werden entrundet, oft mit Doppellaut.grüß → griaß, müde → miad, schön → schian, Küche → Kuchl
u ie → ua iaLange u und ie werden zu Doppellauten.gut → guat, Bub → Bua, lieb → liab, Knie → Knia
-st → -schDas Tiroler Erkennungszeichen: 2. Person und „ist" enden auf -sch.du bist → du bisch, du hast → du håsch, ist → isch, du kommst → du kimmsch
a → åDas a klingt dunkel, fast wie o. Viele schreiben es als å.was → wås, Alm → Ålm, halb → hålb, krank → krånk
k → kchAm Wortanfang wird k mit Reibelaut gesprochen. Geschrieben wird meist nur k.Kuh → Kchua, kalt → kchålt, Kind → Kchind, Käse → Kchas
-en → -nDas e in Endungen fällt weg.machen → måchn, trinken → trinkn, morgen → morgn, Knödel → Knödl
kleine WörterEin paar Wörter muss man einfach lernen.nicht → nit, etwas → eppes, heute → heint, gestern → nechtn, nur → lei, das (jenes) → sell
